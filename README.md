# Support Atlas

Публичный каталог вакансий: https://toligrim.github.io/support-atlas/

Все записи исследования, фильтры, 40 столбцов, карточки с историей и экспорт CSV. SQLite работает в браузере через sql.js 1.14.2 (MIT, лицензия в vendor/LICENSE); сервер и CDN не нужны. Настройки столбцов хранятся в браузере, фильтры — в URL.

Данные — опубликованный снимок: PASS и наличие записи не гарантируют, что вакансия ещё открыта. Архивные наблюдения и мониторинг компаний подписаны в интерфейсе. База vacancies.sqlite и исходные research-снимки sources/ доступны для скачивания. Изменения базы через сайт не поддерживаются.

Ветка main хранит подготовленный сайт; GitHub Pages публикует ветку production из корня. Сборка ведётся в исходном research-проекте командой python3 -m production.build_pages --output <empty-directory>; в этот репозиторий переносится только готовый снимок, без приватной истории Git. Для локальной проверки: python3 -m http.server 8080.
