# Tech Support Radar

Отдельное read-only приложение для технических вакансий; deploy в **собственный** Cloudflare Worker \`tech-support-radar\` + **свою** D1 \`tech-support-radar-db\`. Работающий \`support-atlas\` и \`support-atlas-journal\` не изменяются.

## Входные данные
Начальный импорт — пользовательский архив \`hh_remote_linux_vpn_cloud_all_2026-10-20.jsonl\` от 20 октября 2026 года. Это **не** свежий онлайн-поиск. В нём 779 разных hh.ru vacancy ID; объявления могут быть закрыты. Исходные фрагменты — snippets, не полные тексты. Сборка поддерживает любую удалённую работу; 5/2 допускается.

## Архитектура
- \`worker.js\`: GET /, /style.css, /app.js, /api/jobs, /api/stats, /api/health. Запись через публичный API недоступна.
- \`index.html\`, \`style.css\`, \`app.js\`: самостоятельный адаптивный frontend.
- \`schema.sql\`: изолированная D1-таблица \`jobs\`.
- Уникальность \`id\` предотвращает дубли в одном снимке.
- \`kind\` и \`score\` — **эвристика** по заголовкам и кратким обязанностям, не AI review. Отдельно показаны технические, смежные, сомнительные и клиентские роли.
- Рейтинги не являются объективной оценкой работодателей.
- Отсутствие упоминаний звонков **не означает** «без звонков».
- Исключена автоматическая синхронизация: MCP HeadHunter недоступен при первоначальном импорте. Для свежих данных потребуется дополнительный импорт и проверка закрытых объявлений.

## Проверки
Проверить \`/api/health\`, \`/api/stats\`, \`/api/jobs?kind=technical\`, HTTP / и /app.js. В Cloudflare D1 контроль \`SELECT COUNT(DISTINCT id) FROM jobs\`. Секреты не требуются: публичная база, только чтение; импорт через авторизованную Cloudflare API-консоль.
