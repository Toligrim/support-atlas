# Russian DevInfra / observability / integration support — batch 04

Date: 2026-10-10

## Goal

Search less obvious Russian IT vendors around developer infrastructure, observability/monitoring, integration/API platforms, communications and networking for current remote support roles that fit the project hard filters.

Hard filters stayed unchanged:

- no office/hybrid/onsite/travel requirement;
