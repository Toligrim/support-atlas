# Russian B2B SaaS / DevTools / API support — batch 03

Date: 2026-10-10

## Goal

Search a less obvious layer of the Russian IT market: B2B SaaS, DevTools-adjacent, API/integration, monitoring and product-platform vendors where support is more likely to be ticket/chat/email oriented than classic phone helpdesk.

Hard filters remained unchanged:
- fully remote and workable from Russia;
- no mandatory office/hybrid/onsite/travel;
- no night shift or day/night rotation;
- no mandatory night on-call / regular after-hours duty;
- no phone-primary/call-center roles;
- no sales-heavy duties.
