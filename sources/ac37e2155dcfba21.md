# Adjacent operations / monitoring / junior infrastructure research — batch 10

Date: 2026-10-10

## Goal

Broaden entry-level vacancy-first discovery beyond titles containing `technical support`, toward roles that are operationally similar and can serve as an entry path into support / infrastructure / DevOps / SRE:
- NOC / monitoring;
- operations support;
- application support;
- junior infrastructure;
- junior system administration;
- incident response / first-line operations;
- junior DevOps.

Hard filters remained unchanged:
- fully remote and workable from Russia;
- no night shifts or day/night rotation;
- no mandatory after-hours/on-call;
- no phone-primary/call-center work;
- no hard education/student-status blocker;
- no office/hybrid requirement.

## Scope and result

20 vacancy/role rows were recorded in `data/ru-adjacent-ops-support-batch-2026-10-10-10.csv` after deduplication against prior batches.

Result:
- PASS: 4
- CONDITIONAL: 3
- WATCH: 4
- REJECT: 9

This pass was productive because broadening the titles surfaced multiple roles that are materially more technical than standard L1 HelpDesk while still realistic for a candidate with practical Linux/network/VPN experience but no classical corporate support history.
