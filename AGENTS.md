# Инструкции для агентов

- Публичный интерфейс редактируется в корне; Worker API находится в `src/worker.js`, D1-схема — в `migrations/`. Сборка `npm run build` копирует в `dist/` только публичные runtime assets.
- `vacancies.sqlite`, `metadata.json`, `sources.json` и `sources/` — research-снимок. Меняй данные в исходном research-проекте, затем переноси его сборку; не редактируй снимок вручную.
- Журнал откликов хранится отдельно в D1. Не добавляй его данные или секреты в публичные assets, research-базу или Git. Worker Secrets задаются через Wrangler.
- Для проверки используй `npm test`; для просмотра сайта локально — `npm run dev`. Файлы `vendor/` — закреплённая версия sql.js, обновляй их только при отдельной необходимости.
